## K1
Prefiks `ke-` lisan untuk makna pasif atau tak sengaja. Bentuk resmi hampir selalu `ter-`.

| Tidak baku | Baku |
| --- | --- |
| kejawab | terjawab |
| kebaca | terbaca |
| kebayang | terbayang |
| kepikiran | terpikirkan |
| kelewat | terlewat |
| kepake | terpakai |
| keliatan | terlihat |
| kebawa | terbawa |
| kejebak | terjebak |
| ketinggalan | tertinggal |
| kepencet | tertekan, terpencet |
| kedeteksi | terdeteksi |
| kesebar | tersebar |
| keurus | terurus |
| kekumpul | terkumpul |

Bukan kesalahan: `ke dashboard`, `ke halaman berikutnya`, `ke tim SA`. Itu preposisi arah dan memang ditulis terpisah.

Perhatikan `ketemu`. Padanannya bergantung konteks: `bertemu` untuk orang, `ditemukan` untuk objek atau data.

## K3
Partikel dan interjeksi. Semua dibuang, bukan diganti.

`nih` · `deh` · `dong` · `kok` · `sih` · `lho` · `loh` · `yaudah` · `nah` (di awal kalimat) · `eh` · `wkwk` · `hehe` · `btw` · `oke deh`

Contoh:
- Sebelum: "Nah, ini nih yang sering kelewat sama publisher baru."
- Sesudah: "Ini yang sering terlewat oleh publisher baru."

Pengecualian tunggal: `yuk` boleh bertahan maksimal satu kali per artikel, khusus di kalimat ajakan penutup menuju halaman registrasi.

## K4
Aturan pemisahan `di`.

**Dirangkai** kalau `di-` adalah imbuhan pembentuk kata kerja pasif:
dipromosikan · dibagikan · diklik · didaftarkan · diunggah · disetujui · dicairkan · ditolak · dikirim

**Dipisah** kalau `di` adalah preposisi tempat atau waktu:
di dashboard · di TikTok Shop · di bawah · di antara · di dalam · di sana · di awal bulan · di halaman utama

Uji cepat: kalau kata setelah `di` bisa diganti dengan pertanyaan "di mana?", maka dipisah. Kalau kata itu kata kerja, dirangkai.

Kesalahan yang sering muncul: `di promosikan`, `di klik`, `didalam`, `dibawah`, `didashboard`.

## K6

**Angka**
- Satu sampai sembilan ditulis huruf: `tiga langkah`, `lima brand`.
- Sepuluh ke atas ditulis angka: `12 video`, `48 jam`.
- Angka dengan satuan atau data selalu angka: `5%`, `2 hari`, `Rp50.000`.
- Angka di awal kalimat selalu huruf, atau kalimatnya disusun ulang.

**Mata uang**
`Rp50.000` — tanpa spasi setelah Rp, titik sebagai pemisah ribuan, tanpa `,-` di belakang.

**Persen**
`8%` dirapatkan. Tulis `persen` dengan huruf hanya kalau berdiri sendiri tanpa angka.

**Tanda baca**
- `--` dilarang sebagai penyambung antar klausa. Ganti dengan koma, titik, atau kata sambung.
- Tanda hubung tunggal `-` hanya untuk kata ulang (`langkah-langkah`) dan imbuhan ke istilah asing (`di-review`, meski lebih baik dihindari).
- Tidak ada emotikon di badan artikel.
- Tanda seru maksimal satu per subjudul, jangan beruntun.
- Tanda kutip pakai tanda kutip lurus yang konsisten sepanjang naskah.

## K7
Istilah asing yang **dipertahankan apa adanya**, tanpa terjemahan dan tanpa huruf miring. Ini kosakata kerja audiens Accesstrade.

dashboard · real-time · Sub ID · Bank Konten · CTA · Reels · Carousel · Feed Post · affiliate · publisher · advertiser · campaign · link · commission (dalam nama produk) · engagement · reach · views · hook · thumbnail · shadowban · marketplace · e-commerce · live · voucher · payout

Istilah asing di **luar** daftar itu yang punya padanan lazim, terjemahkan:

| Asing | Indonesia |
| --- | --- |
| revenue | pendapatan |
| benefit | manfaat |
| effort | usaha |
| challenge | tantangan |
| impact | dampak |
| insight | wawasan, temuan |
| tools | alat, perangkat |
| mindset | pola pikir |
| improve | meningkatkan |
| update | memperbarui, pembaruan |
| target | sasaran (kalau bukan istilah iklan) |
| skill | keterampilan |

Kalau sebuah istilah tidak ada di dua daftar ini, pertahankan bentuk aslinya dan catat di tabel temuan supaya user yang memutuskan. Jangan menerjemahkan istilah teknis secara spekulatif.

## Cara menambah entri

Setiap kali reviewer atau tim PR menandai kata baru, tambahkan barisnya ke kategori yang sesuai beserta bentuk bakunya. Kalau kata itu tidak cocok di tujuh kategori mana pun, buat kategori K8 di bawah dan beri nama yang menjelaskan polanya, bukan sekadar "lain-lain".
