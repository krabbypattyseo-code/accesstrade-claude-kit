# House Style dan Pola EYD Artikel Accesstrade

Versi v1 (2026-11-19). Dipakai bersama skill `eyd-checker`.

## 1. House style

| Aturan | Detail |
|---|---|
| Register | Santai-profesional, sapaan aku-kamu di seluruh badan artikel |
| Dilarang | Tanda pisah panjang dan "--", emoticon, link sumber eksternal di dalam paragraf |
| Istilah Inggris | Dipertahankan: dashboard, real-time, Sub ID, Bank Konten, CTA, Reels, Carousel, Feed Post, dst |
| Fashion | Tulis "Fashion", bukan "Fesyen" |
| Bank Konten | Huruf kapital sebagai istilah produk Accesstrade |
| Miring | Kata serapan Inggris dicetak miring di konteks formal (affiliate, brand, voice over, tone) |
| "cuan" | Boleh di artikel blog. Di materi untuk PR ganti "komisi" atau "pendapatan" |
| "yuk" | Maksimal sekali per artikel, di CTA penutup |
| Framing | Tanpa janji penghasilan (Indah menandai ini secara khusus) dan tanpa framing menakut-nakuti |
| Kotak contoh hook | Contoh hook adalah skrip kreator orang pertama. Register aku-kamu di dalam kotak hook dipertahankan walaupun bagian lain dibakukan |
| Balasan komentar reviewer | Netral, tanpa "aku" dan tanpa sapaan seperti "Kakak" |
| Internal link | Selalu di dalam paragraf sebagai hyperlink, bukan blok link terpisah |
| Slug | Slug artikel optimasi dipertahankan. Perubahan slug dan meta description butuh persetujuan Indah |
| Paragraf pembuka | Menjawab pertanyaan utama langsung dalam 2–3 kalimat (untuk AI Overview) |

## 2. Pola kesalahan EYD (K1–K8)

| Kode | Pola | Contoh |
|---|---|---|
| K1 | Prefiks ke- lisan jadi ter- | kejawab → terjawab, kepakai → terpakai |
| K2 | Bentuk lisan jadi baku | buat → untuk, bikin → membuat, gak/nggak → tidak, cuma → hanya, tiap → setiap, biar → supaya, gampang → mudah, sama → dengan, nyantol → melekat |
| K3 | Partikel pengisi | Hapus partikel yang tidak perlu |
| K4 | di- imbuhan vs kata depan | diatas → di atas, dibawah → di bawah (digarisbawahi tetap) |
| K5 | Awalan me- yang dilesapkan | nyala → menyala, mikirin → memikirkan |
| K6 | Format angka dan persen | "1 sampai 80 persen" → "1% sampai 80%" |
| K7 | Penanganan istilah asing | Konsisten dengan daftar istilah di atas |
| K8 | Kesalahan morfologi | mempengaruhi → memengaruhi |

## 3. Prinsip SEO dan konten

- Skor keunikan di atas 70% = artikel baru (Jalur A). Di bawah 70% = optimasi (Jalur B) atau topik ditolak.
- Cek internal link dengan membuka artikel Accesstrade terdekat (sidebar sering menampilkan artikel cluster yang tidak muncul di pencarian site:).
- Untuk SERP yang didominasi AI Overview, masalahnya dibingkai sebagai kesiapan dikutip AI (GEO), bukan sekadar ranking.
- Brief dan drafting adalah langkah terpisah. Jangan menanyakan parameter drafting sebelum Harist memanggil /drafting.

## 4. Visual

- Palet brand: Navy #1A1A2E, Orange #F17420, Off-white #F7F7F5, Warm gray #D9D6D1. Di dokumen Word: H1/H2 Orange, H3 Navy.
- Feature image 680x450 landscape, isometric 3D flat-shaded, tanpa teks, logo, atau wajah manusia.
- Infografis, sub image, atau alur: buat dulu HTML statis seukuran slide, lalu screenshot jadi gambar.
- Visual tidak boleh menyiratkan janji penghasilan. Angka di infografis harus disetujui Harist/Michi sebelum produksi.
