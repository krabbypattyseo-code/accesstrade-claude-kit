# Kotak masuk · Scriptwriting

Catatan untuk sesi Scriptwriting: script yang perlu diubah, kalimat yang susah dibaca, teks layar terlalu panjang, foto/klip yang tidak tersedia, permintaan script baru.

Cara menulis: tambahkan satu blok di bawah. Sesi pemilik menandai `[selesai]` setelah dikerjakan (tidak dihapus).

```
## YYYY-MM-DD · dari <sesi> · <judul singkat>
- File terkait: scripts/reels/01-xxx.json (adegan 3)
- Masalah / permintaan: ...
- Kenapa: ...
```
