Catatan untuk sesi Improvement: bug di mesin Remotion atau builder After Effects, tipe adegan/animasi baru, perubahan brand, kiriman teknik baru, temuan dari profil AE editor.

Cara menulis: tambahkan satu blok di bawah. Sesi pemilik menandai `[selesai]` setelah dikerjakan (tidak dihapus).

```
## YYYY-MM-DD · dari <sesi> · <judul singkat>
- File terkait: scripts/reels/01-xxx.json (adegan 3)
- Masalah / permintaan: ...
- Kenapa: ...
```
